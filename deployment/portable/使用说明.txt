雄安新区城市大脑 - Windows 便携版
================================

适用电脑
--------
1. Windows 10 或 Windows 11，64 位（x64）。
2. 建议至少 8 GB 内存、10 GB 可用磁盘空间。
3. Chrome、Edge 等支持 WebGL 2 的现代浏览器。
4. 建议使用独立显卡；集成显卡可以运行，但大场景帧率可能较低。
5. 不需要安装 Python、Node.js、Docker 或 SUMO。

启动
----
1. 完整解压 ZIP，不能直接在压缩包预览窗口中运行。
2. 如果 Windows 提示“路径太长”，请将 ZIP 移到 C:\Xiongan 后再解压。
3. 双击“启动城市大脑.cmd”。“启动3D演示.cmd”是兼容入口，功能相同。
4. 等待浏览器打开：http://127.0.0.1:5177/?view=3d
5. 启动器会自动运行 BASE 工况、fixed-time 算法的真实 SUMO 仿真。

如果电脑无法正确显示中文文件名，也可以双击功能完全相同的
“START_3D_DEMO.cmd”。

停止
----
演示结束后双击“停止3D演示.cmd”。

首次检查
--------
可先双击“检查运行环境.cmd”。它会检查内置 Python 依赖、SUMO、真实 TraCI
实验、场景、河北离线 OSM 数据、后端接口和 Unity WebGL 静态资源。检查结束后
会自动停止测试进程。

常见问题
--------
- 端口 5177 被占用：在 PowerShell 中运行
  .\start_portable.ps1 -Port 5187
- 浏览器没有自动打开：手动访问 http://127.0.0.1:5177/?view=3d
- Windows 安全提示：确认文件来自可信发送者后再允许运行；不要关闭系统防护。
- 页面长时间停留在 Unity 加载：首次加载约 160 MB 场景数据，请等待；同时关闭
  占用显存较高的软件，并确认浏览器已启用硬件加速。
- 场景生成页的中文背景地图来自在线地图服务，需要网络；河北 OSM 路网快照、
  路网解析、SUMO 仿真、2D/3D 页面和已有场景均已随包提供，可在离线状态运行。
- 错误日志：runtime-state\logs\server.stderr.log

范围说明
--------
本包仅保证在 Windows x64、支持 WebGL 2 且未被安全策略禁止运行本地程序的电脑上
运行。公司终端管控、杀毒软件拦截、过旧显卡驱动或不支持 WebGL 2 的硬件可能
阻止启动，这些环境限制无法由压缩包本身规避。
