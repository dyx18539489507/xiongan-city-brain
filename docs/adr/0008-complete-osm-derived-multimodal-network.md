# ADR 0008：在完整 OSM 上派生多主体网络

状态：接受（2026-08-06）

## 决策

冻结主办方/既有机动车底网，不覆盖 `rongdong.control.net.xml`。自行车、电动自行车、行人道、横道、walking area 和条件并行信号全部生成到可重建的 `rongdong.multimodal.net.xml`。K01—K08/B01—B12 仅是控制观测标识，不裁剪完整 OSM，也不限制所有 OD 必须经过这些点。

## 理由与边界

这同时保留真实地理关系、可重复生成和底网完整性。OSM 没有横道或平面交叉证据时不人工伪造；功能区和交通需求明确标为工程建模，未做现场标定。
