# ADR-0001：双场景体系与容东参数迁移

- 状态：已接受
- 日期：2026-08-05（控制区选点修订）

## 背景

主办方提供20个典型路口的独立Excel和PNG，以及4个独立单路口SUMO案例。影像配准表明这些路口分布在雄县、雄安站、容城县和容东片区，并非局部连续20路口网络。项目同时需要验证多路口拥堵传播、上游限流和云边协同。

## 决策

保留两套场景：

1. `official_20_independent` 完整承载主办方20个独立路口；
2. `xiongan_rongdong_20` 使用容东真实道路拓扑，保留官方14、15、17、18、19、20六个位置锚点，并以14个直接相邻的OSM交叉口构成紧凑连通控制区。官方13和16不强行纳入主控制区，但继续完整保留在`official_20_independent`中。

新增参数不直接复制单个Excel，而采用拓扑条件的多捐赠路口融合、容量缩放、转向平滑、OD流量守恒和Webster配时校准。所有新增值标记为 `modeled_from_organizer_data`。

区域OD入口和出口按20路口控制区边界生成，路线池只接收至少经过5个受控路口的可行路径，并保留经核心走廊的替代路径。这样保证控制算法面对真实的上下游耦合，而不是只在完整OSM底图上运行与受控路口无关的车辆。

## 后果

- 优点：同时保留官方证据和真实连续路网；算法主体可在未来更换真实OSM或官方GIS而不重构。
- 代价：新增14路口不是实测参数，需要明确不确定性并进行多种子和参数扰动实验。
- 禁止：不得把估算坐标或迁移参数描述为主办方实测、高精地图或运营级数字孪生。
