# B0-B3 四算法体系

| 编号 | 实现 | 区域信息 | 下游饱和保护 | 失效行为 |
|---|---|---|---|---|
| B0 | FixedTimeController | 无 | SUMO 原始固定方案 | 最终安全回退 |
| B1 | ActuatedController | 无 | 本地存在检测 | 保持当前安全相位 |
| B2 | MaxPressureController | 无 | 出口占有率进入压力并抑制放行 | 固定配时 |
| B3 | CoordinatedMaxPressureController 2.0 | 30/60/120 s 图时序在线预测、云端目标、剩余容量、动态周期与偏移 | 置信度门控、预测溢出惩罚、独立安全内核 | 预测未就绪时使用当前状态，策略过期后退回 B2 |

所有算法实现统一 `initialize/reset/observe/decide/feedback/health/close` 协议，通过注册表发现并校验配置。算法只能返回解释性决策，不能直接访问数据库、前端或 TraCI。

最大压力按“进口排队 - 出口可用容量惩罚”计算相位分数，并加入路口级最短绿、最大绿和切换惩罚。B3 的 `online-graph-rls-v1` 使用车道进入/离开率、队列、占有率、下游占有率和走廊邻接风险在线更新，输出 30/60/120 s 到达、队列、溢出风险和置信度；控制器默认选取 60 s 预测，置信度低于 0.55 时自动使用当前状态，不产生第五套控制逻辑。B3 同时引入云端限流、疏散优先级、动态周期、走廊偏移和策略 TTL，并把车速引导限定在 B3 全系统方案中。边缘始终拥有最终执行权，切相位必须经过当前绿、黄灯、全红、目标绿的显式路径。

STGNN、MPC、MARL 采用独立的高级模型 artifact 协议：必须提供版本、输入输出签名、SHA-256、训练完成和验证通过证据才能激活。当前没有合格模型文件，因此不把这些扩展描述为已训练模型。现有 B3 的在线 RLS 是可复现的轻量预测器，不冒充神经网络。
