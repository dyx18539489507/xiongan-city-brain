# Web 3D 当前已知限制

本文件只列真实未关闭项。总验收见 `docs/3d/full_requirement_acceptance.md`。

## 数据真实性

- `xiongan_rongdong_20` 是 OSM/主办方锚点与工程配置形成的仿真网络，未经过现场流量、高精测绘或数字孪生校准；
- 79 个建筑 footprint 多数缺高度，使用已记录的工程高度；树、路灯、RSU、摄像头属于工程布设，不是设备台账；
- 路侧设备可绑定当前 SUMO TLS 和系统通信状态，但没有真实 RF 覆盖、摄像机视频或物理 RSU 遥测；
- baseline/算法结果只展示实际 result 数字，不从未配对实验推断算法收益。

## 视觉资产

- 公交、卡车、配送车和 K06 车辆已有真实 Draco optimized GLB；其他轿车类别仍共享轻量车身变化；
- K06 已有按需加载的原创 Blender 英雄建筑，近景人物已有低骨骼蒙皮；其他区域建筑、人物、自行车和家具仍以低成本程序资产为主，缺少高精人物、独立 SUV 与精细电动车 GLB；
- 实际 ETC1S KTX2 已用于道路，但尚未把所有车辆/建筑纹理批量转为 KTX2；
- OSM 覆盖稀疏区域仍可能显得空，不能称为真实雄安建筑复刻。

## 性能与稳定性

- 当前冻结代码的 MX250 45 组合平均 15.27 FPS、中位 15.0，最低组合平均 8.1，最低 P1 1.1；天气/相机切换和机器持续高负载后仍有明显长帧；
- 当前冻结 checkout 的 1811.2 秒高负载长稳没有页面错误、采样超时或崩溃，但平均仅 19.31 FPS、最低窗口 16.3，证明的是可运行性而不是高峰 25–30 FPS；
- 当前长稳仿真只推进到 T+663/3600 s；Heap +0.39 MB/min 正斜率与实体持续增长混杂，尚不能证明零泄漏；
- 浏览器无法可靠读取独显显存占用，当前显存值只能由纹理/geometry 估算；
- Three.js 与 ECharts 生产 chunk 仍超过 500 kB；ECharts 已延迟加载，Three.js 是首屏核心依赖。

## 协议与回放

- 当前 SUMO/实体真值通常为 1 Hz，前端在 30 FPS 插值；没有实现原建议的约 10 Hz 真值推送；
- Replay 已流式解码，但只保存 20 个目标路口的汇总指标，不保存每条 lane 的完整历史指标；
- 100 MB/120,000 帧是前端硬上限；超过需分段索引而不是提高上限；
- 60 秒 DemoDirector 是工程 smoke，尚未绑定两组同 seed、真实完成的 6 分钟 baseline/算法比赛脚本。

## 可选与外部依赖

- Cesium CityOverviewMode 未实现；Three.js 正式模式不与 Cesium 同时常驻；
- 真实 MQTT 集成测试在未配置外部 broker 时仍跳过；这不影响本机 SUMO/WebSocket，但不构成真实车路云网络验收；
- 没有 UE、CARLA、光追、Lumen、Nanite 或 WebGPU 正式依赖。

## 当前诚实结论

当前是可运行、可回放、可交互、可用 MX250 演示的工程级 20 路口 Web 3D 数字孪生闭环；不是现场标定的城市级生产数字孪生，也不是电影级资产库。当前 45 组合平均 15.27 FPS，不能写成稳定 25–30 FPS；资产覆盖、长帧和仿真全时长仍需继续优化。
