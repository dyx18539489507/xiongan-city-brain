# DemoDirector 与比赛演示脚本

## 已实现

- `CameraManager` 按毫秒时长插值 position/target/FOV；
- `camera_presets.json` 保存全域、走廊、K06、RSU、监控、驾驶员、巡航等配置；
- 页面有全域、走廊、城市、车辆跟随、非机动车、行人、事件、RSU、监控、驾驶员、巡航、选中路口 12 个视图；
- RSU/监控视角来自 scene 设备位置，驾驶员视角来自当前 SUMO 车辆位置/角度；
- `DemoDirector` 严格按有序 cue 切换视图、天气和 real/analysis；手动选镜头立即停止导演；
- LIVE 与 REPLAY 使用同一 Director/Renderer，导演不能改实体轨迹、TLS 或 KPI。

## 正式比赛脚本预留

原建议 00:00–05:50 的全域、拥堵、协同、绿波、施工、云边响应、指标对比顺序仍保留为策划模板。绑定前必须先完成同 scene/profile/seed 的真实 Baseline 与算法实验，并把实际 experiment ID、事件时间和指标方向写入配置；DemoDirector 不得修改数据制造改善。

## 限制

- cue 当前按墙钟推进，不自动驱动 replay seek；
- 实体/事件视图在目标不存在或不在 scene bounds 时回退，不把相机飞到空场景；
- 60 秒 smoke 已通过自动测试，正式 6 分钟双实验脚本仍未验收。
