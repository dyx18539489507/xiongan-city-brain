# 公平实验协议

正式机器规约见 `specs/benchmark_protocol.yaml`。

同一个随机种子内固定完整 OSM 派生路网、机动车/自行车/电动车/行人 OD、车型、发车时间、时长、扰动和通信条件，只切换算法。正式设计为 B0—B3 × `[11, 23, 37, 41, 59]` × 1,800 s；`benchmark-smoke` 使用种子 11 和 20 s，仅验证闭环，不代替正式统计。

输出包含每次运行的原始 JSON、CSV、HTML、SVG、实验参数、场景文件 SHA-256、算法版本、Python/SUMO 环境和时间戳。主要指标分为交通效率、拥堵传播、能耗环境、系统工程和鲁棒性五组。

比较时先报告各种子原始值，再使用 Student-t 分布报告均值、95% 置信区间和最差值。机动车、骑行者和行人分别报告效率与等待；TTC/PET 按代理指标单列。若参与者在仿真截止时仍未清空，应单独报告 `Running/Waiting`，不得把“结构有效”写成“需求完全清空”。没有实际运行的组合显示“尚未运行”，不插补或编造提升率。

截至 2026-08-06，四算法单种子 20 s 冒烟已经实际运行，正式 5 种子长时矩阵尚未完成，因此没有算法优胜或提升百分比结论。
