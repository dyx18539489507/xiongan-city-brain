# 驾驶舱视觉与交互决策

- 视觉主张：以“夜间交通指挥台”为主视觉，深色沥青底、冷青色运行态和单一琥珀色故障态，
  让真实地理拓扑成为画面中心，而不是用卡片拼贴抢夺注意力。
- 内容计划：顶部运行状态轨；中央20路口拓扑与右侧路口检查器；底部真实指标曲线与事件时间线；
  最下方实验和故障控制区。
- 交互主张：新数据沿核心走廊轻微脉冲；信号相位变更使用短促过渡；故障和降级事件从时间线顶部
  滑入。所有动画均尊重 `prefers-reduced-motion`。

页面初始值使用“—/尚未运行”，不生成演示数字。路口位置和拓扑边来自
`controlled_intersections.json`，运行状态来自 `/ws/v1/realtime`。
