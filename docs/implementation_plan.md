## 本轮收尾顺序

1. 已终止优化前、超过 85 分钟仍无结果的 1,800 s 闭环，并保留未完成痕迹。
2. 已完成多主体轨迹持久化、文档与 ADR 更新。
3. 已完成 Ruff、Mypy、100 个 Python 测试及前端 Vitest/构建/Playwright。
4. 已用单快照优化路径实跑固定配时、云边协调、故障和四算法冒烟并记录实时因子。
5. 已重建最终 Docker 镜像并通过物理 Mosquitto + RSU + Timescale 端到端验收。
6. 待办：在性能优化/并行实验调度后运行完整 5 种子 × 4 算法 × 1,800 s 正式矩阵；只在实际完成后生成优劣结论。

## 明确排除

- 不改冻结的底层 SUMO 路网。
- 不限制全网只聚焦 20 路口，不物理裁剪独立子网。
- 不做现场实测流量标定或运行级数字孪生宣称。
- 不在缺少训练 artifact 时伪装实现 STGNN、MPC 或 MARL。
