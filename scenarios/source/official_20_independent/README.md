# 主办方独立路口场景源说明

本目录只保存可复现建模配置，不复制或修改主办方原始资料。

原始 Excel 和地图通过环境变量 `TRAFFIC_ORGANIZER_SOURCE_ROOT` 指向仓库外
只读目录；当前环境对应：

```text
D:\程序项目\挑战杯\赛题资料\赛题资料
```

每个独立路口的 SUMO 工程综合以下证据：

1. 主办方 Excel：8 个 15 分钟流量单元格、转向方向和逐相位配时；
2. 主办方 PNG：道路臂是否存在、路口形态和可辨识的车道结构；
3. OSM：公开地图地理中心、道路方向、道路名称/等级和已有车道标签；
4. 工程假设：仅在官方资料和 OSM 都缺失时使用，并在模型清单中单独标记。

这些路口是独立复现案例，不被描述成一个官方连通区域路网。
