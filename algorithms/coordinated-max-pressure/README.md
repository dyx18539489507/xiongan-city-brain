# B3 Predictive Coordinated Max Pressure

B3 把 30/60/120 s 在线图时序预测、置信度门控、云端区域权重、走廊偏移、预测到达/队列/溢出风险和下游剩余容量融合进本地最大压力。信号相位默认保持 B2 的最大压力选择，预测未就绪时在 B3 内使用当前状态，云策略失效时自主退回 B2。

## 自适应车速协同

首次评估快照在任何 B3 车速干预前锁定交通状态，避免干预结果反过来改变模式分类：

- 网络平均速度不低于 `4.65 m/s` 时进入高机动模式。红灯 GLOSA 最低目标为 `3 m/s`，绿灯排队放行覆盖到 `0.5 m/s`，放行目标为 `2 m/s`。该模式绕过效果冷却，但所有指令仍受安全核、车辆动力学和 SUMO 跟驰约束。
- 其余情况进入拥堵模式。红灯 GLOSA 最低目标为 `1 m/s`，绿灯排队放行覆盖到 `1 m/s`，放行目标为 `4 m/s`。系统按 30 s 窗口评估效果；速度下降至少 0.5% 且排队未下降 5% 时，冷却 20 s 并释放车辆限速覆盖。

逐秒样本记录状态分类、基准速度、GLOSA 最低目标、干预开关和效果门控状态，支持复核每次干预为何生效或退出。实现位于 `src/traffic_platform/algorithms/coordinated.py`、`src/traffic_platform/vehicle_agent/agent.py` 与 `src/traffic_platform/cloud_service/predictor.py`。

## 实时执行边界

边缘决策以 `100 ms` 为性能目标并单独记录目标违约次数；`250 ms` 为控制周期内的硬超时门限，只有越过硬门限才触发安全回退并使严格最优判决失败。这样可以区分算法持续过载与非实时操作系统的短时调度抖动，同时保留完整的时延审计证据。
